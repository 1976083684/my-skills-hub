# My Skills Hub

个人 Claude Code Skills 合集，汇集日常使用的各类技能。

## AI Coding 一站式

按 AI 辅助编码的完整流程分类：

### 需求分析
| 技能 | 说明 |
| --- | --- |
| analysis-business-function | 从源码、UI、API、数据库结构分析现有系统业务模块（只读分析） |
| analysis-prd-doc | PRD 与原型解析，输出模块职责、流程与数据流，检查自洽性与遗漏 |
| analysis-prd-item | 专业术语与功能模块整理为新人易懂的业务笔记 |
| analysis-prd-pre | PRD 评审前对齐分析，输出逐功能评审与问题清单 |

### 需求与设计
| 技能 | 说明 |
| --- | --- |
| brainstorming | 创意工作前的需求探索与设计 |
| create-prd-doc | 标准 PRD 生成（按需求复杂度扩展章节） |
| create-technical-design-doc | 技术设计文档生成、优化与评审（按风险分级裁剪模板） |

### 编码实现
| 技能 | 说明 |
| --- | --- |
| frontend-design | 高质量前端界面设计 |

### 代码优化
| 技能 | 说明 |
| --- | --- |
| code-simplifier | 代码简化与重构 |

### 测试与迁移
| 技能 | 说明 |
| --- | --- |
| create-test-doc | 标准化后端测试文档与测试用例模板生成 |
| create-module-migration-doc | 模块代码迁移前的迁移清单文档生成 |

### 技能管理
| 技能 | 说明 |
| --- | --- |
| find-skills | 发现和安装新技能 |
| skill-creator | 技能创建与评估 |
